# Receipt Digit OCR (OpenCV & Keras)

レシート画像から数字領域を検出し、学習済みモデルを用いて数値を認識するPythonプロジェクトです。画像処理の基礎から機械学習による推論までを一貫して実装しています。

## 特徴

* **画像前処理の最適化**: OpenCVを用い、レシートの感熱紙特有のノイズを低減するための「ガウシアンブラー」や「適応的閾値処理（Adaptive Threshold）」を実装。
* **領域自動抽出**: 輪郭抽出（Contour Detection）アルゴリズムにより、画像内の文字と思われる箇所を自動で矩形（枠）として切り出し。
* **ディープラーニング推論**: Kerasで構築した多層パーセプトロン（MLP）モデルを用い、切り出された画像から数字を特定。

## 技術スタック

* **Python 3.x**
* **OpenCV**: 画像のグレースケール化、二値化、輪郭抽出
* **Keras / TensorFlow**: 数字認識モデルの構築・推論
* **Matplotlib**: 学習データの可視化

## 構成

* `mode.py`: 画像処理メインスクリプト。レシート画像（`receipt.jpg`）を読み込み、数字領域の抽出から保存までを行います。
* `ml.py`: MNISTデータセットを用いたモデルの学習および定義。
* `receipt.h5`: 学習済みのモデルパラメータ。

## 使い方

### 1. 依存ライブラリのインストール

```bash
pip install opencv-python keras tensorflow matplotlib

```

### 2. 画像処理と領域抽出の実行

`mode.py` を実行すると、レシート画像から文字が抽出され、`images` フォルダに個別の文字画像として保存されます。

```bash
python mode.py

```

### 3. モデルの学習（再学習が必要な場合）

```bash
python ml.py

```

## 技術的な工夫点（アピールポイント）
### 1. 頑健な二値化処理
レシートは照明の当たり方によって影ができやすいため、単純な二値化ではなく `cv2.adaptiveThreshold` を採用しています。これにより、画像全体で明るさが均一でない場合でも、精度よく文字を浮き立たせることが可能です。

### 2. 輪郭フィルタリング
`cv2.boundingRect` で得られた領域のうち、極端に小さいノイズや大きすぎる枠を除外するロジックを実装し、誤検知を抑制しています。
